Detecting Collusion in Multi-Agent Systems

AI Security Lab, University of Massachusetts Amherst

Tisya Singh, Leilani Karanja, Ryan Kotwal, Fardeen Riaz Ahamed

This research investigates whether colluding agents in multi-agent systems (MAS) can be identified in real time by analyzing communication channels. Using a simulation framework to generate conversation transcripts across 8 distinct collusion attack types, we evaluated detection accuracy using a Qwen LLM classifier under multiple prompting strategies (zero-shot, in-context learning, and in-context learning with authority nudging).

Key findings:

  • All collusion types were detected with >50% accuracy, with in-context learning (ICL) achieving the highest mean accuracy (0.758)
  • Detection accuracy stabilizes after ~20 messages, suggesting real-time detection potential
  • Detection accuracy increases with colluder count, indicating that coordination among agents strengthens detectable patterns
  • Authority nudge and risk aversion collusion types were easiest to detect; helpful misdirection was hardest
